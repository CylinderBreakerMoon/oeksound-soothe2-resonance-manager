## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Preset Library** | Organize Soothe 2 presets by source type and problem frequency |
| **Sensitivity Notes** | Document sensitivity and depth settings rationale per preset |
| **Source Types** | Categorize presets by vocals, guitars, pianos and other sources |
| **Delta Monitoring** | Log delta monitoring workflow notes per Soothe session |
